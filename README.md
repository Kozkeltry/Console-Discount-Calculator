# Console-Discount-Calculator
Простая консольная программа на C++ для расчета итоговой стоимости покупки с учетом скидочных купонов.

## 🛠 Функционал
* Расчет скидки по коду:
  * `D` / `d` — скидка **10%**
  * `S` / `s` — скидка **20%**
* Обработка некорректных кодов скидок с сохранением исходной стоимости.
* Поддержка ввода дробных сумм (копеек).
* Корректное отображение кириллицы в консоли Windows.

## 💻 Пример работы
```text
Введите сумму покупки: 1250.50
Введите код скидки: d
Итоговая сумма к оплате: 1125.45
```

## ⚙️ Системные требования
* **ОС:** Windows (используется библиотека `<windows.h>` для настройки кодировки консоли).
* **Компилятор:** Любой современный компилятор с поддержкой стандарта C++11 и выше (GCC, Clang, MSVC).
